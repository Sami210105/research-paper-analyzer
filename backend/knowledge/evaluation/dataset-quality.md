High quality dataset indicators:
- Publicly available with a DOI or permanent URL
- Large enough sample for the task (domain-dependent)
- Balanced class distribution or explicitly handled imbalance
- Clear data collection protocol described
- Train/validation/test splits defined and non-overlapping
- No data leakage between splits

Low quality dataset red flags:
- Proprietary data with no access path
- Very small dataset with no justification
- No mention of how data was collected
- Same data used for both training and evaluation
